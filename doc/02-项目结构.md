## 2. 核心目录说明

### 2.1 backend/apps/ - Django应用模块

#### apps.asset - 资产管理
- **models.py**: 数据模型（IDC、设备、账户、服务器等）
- **views.py**: 视图函数和ViewSet
- **serializers.py**: 序列化器
- **urls.py**: URL路由配置
- **tasks.py**: Celery任务
- **consumers.py**: WebSocket消费者（WebSSH）

#### apps.automation - 自动化运维
- **models.py**: 数据模型（采集方案、采集规则、自动化任务等）
- **views.py**: 视图函数
- **tasks.py**: 设备采集任务
- **tools/**: 各厂商处理类（H3C、华为、思科等）
- **firewall/**: 防火墙相关功能
- **consumers.py**: WebSocket消费者

#### apps.config_center - 配置管理中心
- **models.py**: 数据模型（配置备份、配置模板、合规规则等）
- **views.py**: 视图函数
- **tasks.py**: 配置备份任务
- **config_parse/**: 配置解析工具
- **git_tools/**: Git操作工具
- **compliance.py**: 合规性检查

#### apps.device_api - 设备API管理（新版）
- **models.py**: 数据模型（采集方案、子方案等）
- **models_api.py**: API模型和数据处理
- **views.py**: 视图函数
- **tasks.py**: 采集任务
- **processors.py**: 数据处理器
- **fields_mapping.py**: 字段映射

#### apps.system - 系统管理
- **views/**: 视图模块
  - **menu.py**: 菜单管理
  - **role.py**: 角色管理
  - **dept.py**: 部门管理
  - **login.py**: 登录相关
  - **operation_log.py**: 操作日志
  - **login_log.py**: 登录日志

#### apps.users - 用户管理
- **models.py**: 用户模型
- **views.py**: 用户视图
- **serializers.py**: 用户序列化器

### 2.2 backend/utils/ - 工具类库

#### utils.connect_layer/ - 设备连接层
- **snmp/**: SNMP相关工具
- **textfsm/**: TextFSM模板文件
- **auto_main.py**: 自动化主程序
- 各厂商连接类实现

#### utils.db/ - 数据库工具
- **mongo_ops.py**: MongoDB操作工具
- 数据库连接管理

#### utils.custom/ - 自定义工具
- **middleware.py**: 中间件
- **pagination.py**: 分页器
- **exception.py**: 异常处理
- **swagger.py**: Swagger配置

### 2.3 backend/bus/ - 消息总线
- **bus_async.py**: 异步消息总线（基于Redis）
- **bus_sync.py**: 同步消息总线
- **redisHelper.py**: Redis辅助工具

### 2.4 backend/service_mesh/ - 服务网格
- **alert_gateway.py**: 告警网关
- **msg_gateway.py**: 消息网关
- **south_gateway.py**: 南向网关（设备采集服务）

### 2.5 backend/driver/ - 驱动管理
- **driver_auto_loader.py**: 驱动自动加载器
- **drivers/**: 驱动实现目录

## 3. 配置文件说明

### 3.1 config/config.json
主配置文件，包含：
- 数据库连接信息（MySQL、MongoDB、Redis）
- 服务配置
- 其他系统配置

### 3.2 backend/netaxe/settings.py
Django项目设置：
- 应用配置（INSTALLED_APPS）
- 数据库配置
- 中间件配置
- 日志配置
- Celery配置
- REST Framework配置
- 缓存配置

### 3.3 docker-compose.yml
Docker Compose配置，定义服务：
- base-web: 前端服务
- base-backend: 后端服务
- base-nginx: Nginx代理
- celery-default: Celery默认队列Worker
- celery-config: Celery配置队列Worker

## 4. 数据存储

### 4.1 MySQL数据库
存储结构化数据：
- 用户、角色、权限
- 设备信息（CMDB）
- 配置备份记录
- 任务记录
- 系统配置

### 4.2 MongoDB数据库
存储采集数据和解析结果：
- `Automation` 数据库：
  - `layer3interface`: 三层接口信息
  - `arp`: ARP表
  - `mac`: MAC地址表
  - `lldp`: LLDP邻居信息
  - `networkdevice`: 设备信息快照
  - 其他采集数据集合

### 4.3 Redis
- 缓存数据
- Celery消息队列
- WebSocket Channel Layer
- 会话存储

## 5. 日志文件

日志文件位于 `backend/logs/` 目录：
- `server.log`: 服务器日志
- `db.log`: 数据库日志
- `automation.log`: 自动化任务日志
- `celery.log`: Celery任务日志
- `websocket.log`: WebSocket日志
- `webssh.log`: WebSSH日志
- `middleware.log`: 中间件日志
- `ipam.log`: IPAM日志

## 6. 媒体文件

媒体文件位于 `backend/media/` 目录：
- `admin_ssh_records/`: SSH登录记录
- `automation/`: 自动化相关文件
- `device_config/`: 设备配置文件
- `topology/`: 拓扑图文件
- `upload/`: 上传文件
