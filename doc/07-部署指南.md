# 部署指南

## 1. 部署概述

NetAxe平台支持多种部署方式：
- Docker Compose部署（推荐）
- 传统方式部署
- Kubernetes部署（可选）

## 2. 环境要求

### 2.1 服务器要求
- **CPU**: 4核以上
- **内存**: 8GB以上
- **磁盘**: 100GB以上（根据数据量调整）
- **操作系统**: Linux (Ubuntu 20.04+ / CentOS 7+)

### 2.2 软件要求
- Docker 20.10+
- Docker Compose 1.29+
- 或直接安装：
  - Python 3.8+
  - MySQL 5.7+ / 8.0+
  - MongoDB 4.0+
  - Redis 5.0+
  - Nginx 1.18+

## 3. Docker Compose部署（推荐）

### 3.1 准备工作

#### 克隆项目
```bash
git clone https://github.com/iflytek/NetAxe.git
cd NetAxe
```

#### 配置环境变量
编辑 `config/config.json`:
```json
{
  "mysql_host": "mysql_host",
  "mysql_port": 3306,
  "mysql_user": "root",
  "mysql_password": "your_password",
  "mysql_db": "netaxe",
  "mongodb_host": "mongodb_host",
  "mongodb_port": 27017,
  "mongodb_user": "",
  "mongodb_password": "",
  "mongodb_db": "Automation",
  "redis_host": "redis_host",
  "redis_port": 6379,
  "redis_pwd": "",
  "local_dev": false
}
```

### 3.2 构建和启动

#### 创建Docker网络
```bash
docker network create docker_netaxe
```

#### 构建镜像
```bash
docker-compose build
```

#### 启动服务
```bash
docker-compose up -d
```

#### 查看服务状态
```bash
docker-compose ps
```

#### 查看日志
```bash
# 查看所有服务日志
docker-compose logs -f

# 查看特定服务日志
docker-compose logs -f base-backend
docker-compose logs -f celery-default
```

### 3.3 初始化数据库

#### 进入后端容器
```bash
docker-compose exec base-backend bash
```

#### 执行数据库迁移
```bash
cd /app
python manage.py migrate
```

#### 初始化数据
```bash
python manage.py init_asset
python manage.py createsuperuser
```

### 3.4 服务访问

- **前端**: http://localhost:32200
- **后端API**: http://localhost:31100/base_platform/
- **Django Admin**: http://localhost:31100/admin/

### 3.5 服务管理

#### 停止服务
```bash
docker-compose stop
```

#### 重启服务
```bash
docker-compose restart
```

#### 停止并删除容器
```bash
docker-compose down
```

#### 更新服务
```bash
# 拉取最新代码
git pull

# 重新构建
docker-compose build

# 重启服务
docker-compose up -d
```

## 4. 传统方式部署

### 4.1 安装依赖

#### 安装Python依赖
```bash
cd backend
pip install -r requirements.txt
```

#### 安装系统依赖
```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install -y mysql-server mongodb redis-server nginx

# CentOS
sudo yum install -y mysql-server mongodb redis nginx
```

### 4.2 配置数据库

#### MySQL配置
```bash
# 创建数据库
mysql -u root -p
CREATE DATABASE netaxe CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER 'netaxe'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON netaxe.* TO 'netaxe'@'localhost';
FLUSH PRIVILEGES;
```

#### MongoDB配置
```bash
# 启动MongoDB
sudo systemctl start mongod
sudo systemctl enable mongod
```

#### Redis配置
```bash
# 启动Redis
sudo systemctl start redis
sudo systemctl enable redis
```

### 4.3 配置应用

#### 编辑配置文件
编辑 `config/config.json`，配置数据库连接信息。

#### 初始化数据库
```bash
cd backend
python manage.py migrate
python manage.py init_asset
python manage.py createsuperuser
```

### 4.4 启动服务

#### 使用uWSGI启动Django
```bash
# 安装uWSGI
pip install uwsgi

# 启动（使用配置文件）
uwsgi --ini uwsgi.ini
```

#### 使用Gunicorn启动Django
```bash
# 安装Gunicorn
pip install gunicorn

# 启动
gunicorn -w 4 -b 0.0.0.0:8000 netaxe.wsgi:application
```

#### 启动Daphne（WebSocket）
```bash
daphne -b 0.0.0.0 -p 8001 netaxe.asgi:application
```

#### 启动Celery Worker
```bash
# 默认队列
celery -A netaxe worker -l info -Q default -D

# 配置备份队列
celery -A netaxe worker -l info -Q config_backup -D

# 配置队列
celery -A netaxe worker -l info -Q config -D
```

#### 启动Celery Beat
```bash
celery -A netaxe beat -l info -D
```

### 4.5 配置Nginx

#### 编辑Nginx配置
编辑 `nginx/nginx.conf` 或创建新的配置文件：

```nginx
upstream backend {
    server 127.0.0.1:8000;
}

upstream websocket {
    server 127.0.0.1:8001;
}

server {
    listen 80;
    server_name your_domain.com;

    # 静态文件
    location /static/ {
        alias /path/to/backend/static/;
    }

    # 媒体文件
    location /media/ {
        alias /path/to/backend/media/;
    }

    # WebSocket
    location /base_platform/ws/ {
        proxy_pass http://websocket;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # API接口
    location /base_platform/ {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 前端
    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }
}
```

#### 重启Nginx
```bash
sudo nginx -t
sudo systemctl restart nginx
```

### 4.6 使用Supervisor管理进程

#### 安装Supervisor
```bash
pip install supervisor
```

#### 创建Supervisor配置
编辑 `supervisord.conf`:

```ini
[program:netaxe-django]
command=/path/to/venv/bin/gunicorn -w 4 -b 0.0.0.0:8000 netaxe.wsgi:application
directory=/path/to/backend
user=www-data
autostart=true
autorestart=true

[program:netaxe-daphne]
command=/path/to/venv/bin/daphne -b 0.0.0.0 -p 8001 netaxe.asgi:application
directory=/path/to/backend
user=www-data
autostart=true
autorestart=true

[program:netaxe-celery-default]
command=/path/to/venv/bin/celery -A netaxe worker -l info -Q default
directory=/path/to/backend
user=www-data
autostart=true
autorestart=true

[program:netaxe-celery-beat]
command=/path/to/venv/bin/celery -A netaxe beat -l info
directory=/path/to/backend
user=www-data
autostart=true
autorestart=true
```

#### 启动Supervisor
```bash
supervisord -c supervisord.conf
supervisorctl -c supervisord.conf status
```

## 5. 生产环境优化

### 5.1 性能优化

#### Django优化
- 启用缓存（Redis）
- 使用数据库连接池
- 启用Gzip压缩
- 使用CDN加速静态资源

#### Celery优化
- 合理设置Worker并发数
- 使用任务优先级
- 监控任务执行情况

#### 数据库优化
- 创建合适的索引
- 定期清理历史数据
- 使用数据库读写分离（可选）

### 5.2 安全配置

#### 修改Django设置
```python
# settings.py
DEBUG = False
ALLOWED_HOSTS = ['your_domain.com']
SECURE_SSL_REDIRECT = True
SESSION_COOKIE_SECURE = True
CSRF_COOKIE_SECURE = True
```

#### 配置HTTPS
使用Let's Encrypt获取SSL证书：
```bash
sudo apt-get install certbot python3-certbot-nginx
sudo certbot --nginx -d your_domain.com
```

#### 防火墙配置
```bash
# 开放必要端口
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 22/tcp
sudo ufw enable
```

### 5.3 监控和日志

#### 日志管理
- 配置日志轮转
- 集中日志管理（ELK Stack可选）
- 设置日志告警

#### 监控指标
- 服务器资源使用（CPU、内存、磁盘）
- 数据库连接数
- Celery任务执行情况
- API响应时间

#### 使用Flower监控Celery
```bash
celery -A netaxe flower --port=5555
# 访问 http://your_domain.com:5555
```

## 6. 备份和恢复

### 6.1 数据备份

#### 数据库备份脚本
```bash
#!/bin/bash
# backup.sh

# MySQL备份
mysqldump -u root -p netaxe > /backup/mysql/netaxe_$(date +%Y%m%d).sql

# MongoDB备份
mongodump --db Automation --out /backup/mongodb/$(date +%Y%m%d)

# Redis备份
redis-cli BGSAVE
cp /var/lib/redis/dump.rdb /backup/redis/dump_$(date +%Y%m%d).rdb

# 配置文件备份
tar -czf /backup/config/config_$(date +%Y%m%d).tar.gz config/
```

#### 定时备份
```bash
# 添加到crontab
0 2 * * * /path/to/backup.sh
```

### 6.2 数据恢复

#### MySQL恢复
```bash
mysql -u root -p netaxe < /backup/mysql/netaxe_20240101.sql
```

#### MongoDB恢复
```bash
mongorestore --db Automation /backup/mongodb/20240101/Automation
```

## 7. 故障排查

### 7.1 常见问题

#### 服务无法启动
- 检查端口是否被占用
- 检查配置文件是否正确
- 查看日志文件

#### 数据库连接失败
- 检查数据库服务是否运行
- 检查连接信息是否正确
- 检查防火墙设置

#### Celery任务不执行
- 检查Redis连接
- 检查Worker是否运行
- 查看Celery日志

#### WebSocket连接失败
- 检查Daphne是否运行
- 检查Nginx配置
- 检查Redis Channel Layer

### 7.2 日志查看

#### Django日志
```bash
tail -f backend/logs/server.log
```

#### Celery日志
```bash
tail -f backend/logs/celery.log
```

#### Nginx日志
```bash
tail -f /var/log/nginx/error.log
tail -f /var/log/nginx/access.log
```
