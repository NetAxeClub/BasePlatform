# 项目概述

## 1. 项目简介

NetAxe 是一个让 NetDevOps 更简单、更快速、更高效的快速集成前后端一体化框架。它提供了完整的网络设备管理、自动化运维、配置管理等功能，帮助运维团队高效管理网络基础设施。

### 1.1 核心特性

- **资产管理**: 完整的网络设备CMDB管理，支持设备信息、账户管理、IP地址管理等
- **自动化运维**: 支持设备信息采集、自动化任务编排、任务调度等
- **配置管理**: 配置备份、配置差异比较、配置合规性检查、配置模板管理
- **WebSSH**: 基于Web的SSH终端，支持网络设备和服务器远程管理
- **接口管理**: 设备接口信息采集、接口利用率统计
- **拓扑管理**: 网络拓扑图生成和管理
- **用户权限**: 完整的用户、角色、权限管理体系

### 1.2 技术栈

#### 后端技术
- **框架**: Django 3.2.25
- **API框架**: Django REST Framework 3.13.1
- **异步支持**: Django Channels 2.3.1 (WebSocket)
- **任务队列**: Celery 5.4.0 + Redis
- **数据库**: MySQL (主数据库) + MongoDB (数据存储) + Redis (缓存/消息队列)
- **网络设备连接**: Netmiko 3.4.0, Nornir 3.3.0, ncclient 0.6.16
- **配置解析**: TextFSM 1.1.0, TTP 0.9.2
- **模板引擎**: Jinja2 (Nornir-Jinja2)

#### 前端技术
- Vue.js (前端框架)
- Element UI (UI组件库)

#### 部署技术
- Docker & Docker Compose
- Nginx (反向代理)
- uWSGI / Gunicorn (WSGI服务器)
- Daphne (ASGI服务器)

### 2.2 核心组件

#### 2.2.1 Django 应用模块
- **apps.asset**: 资产管理模块
- **apps.automation**: 自动化运维模块
- **apps.config_center**: 配置管理中心
- **apps.device_api**: 设备API管理（新版采集方案）
- **apps.system**: 系统管理（菜单、角色、权限等）
- **apps.users**: 用户管理
- **apps.topology**: 拓扑管理
- **apps.int_utilization**: 接口利用率统计
- **apps.route_backend**: 路由后端管理
- **apps.dcs_control**: DCS控制管理

#### 2.2.2 基础设施组件
- **bus**: 消息总线（同步/异步）
- **database**: 数据库连接管理（同步/异步）
- **driver**: 驱动自动加载器
- **rpc**: RPC服务
- **service_mesh**: 服务网格（告警网关、消息网关、南向网关）
- **utils**: 工具类库（SSH连接、SNMP、MongoDB操作等）

#### 2.2.3 任务处理
- **Celery**: 异步任务处理
- **Celery Beat**: 定时任务调度
- **任务队列**: 
  - `default`: 默认队列
  - `config_backup`: 配置备份队列
  - `config`: 配置相关任务队列

### 2.3 数据流

#### 设备采集流程
```
定时任务/手动触发
    ↓
获取设备列表 (MySQL)
    ↓
下发采集任务 (Celery)
    ↓
连接设备 (Netmiko/Netconf)
    ↓
执行采集命令
    ↓
解析数据 (TextFSM/TTP)
    ↓
存储数据 (MongoDB)
    ↓
更新缓存 (Redis)
```

#### 配置备份流程
```
定时任务/手动触发
    ↓
获取设备列表
    ↓
连接设备获取配置
    ↓
保存配置到Git仓库
    ↓
记录备份信息 (MySQL)
```

## 3. 技术特点

### 3.1 异步处理
- 使用 Celery 处理耗时任务（设备采集、配置备份等）
- 使用 Django Channels 支持 WebSocket（WebSSH、实时消息推送）
- 支持异步数据库操作

### 3.2 可扩展性
- 插件化架构，支持自定义驱动和处理类
- 模块化设计，各功能模块独立
- 支持多厂商设备（H3C、华为、思科、山石等）

### 3.3 数据存储
- MySQL: 存储结构化数据（设备信息、用户、配置等）
- MongoDB: 存储采集的原始数据和解析后的数据
- Redis: 缓存和消息队列

### 3.4 安全性
- JWT Token 认证
- 密码加密存储
- 权限控制（基于角色的访问控制）
- API白名单机制
