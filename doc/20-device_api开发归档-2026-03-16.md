  - `DeviceConnectionManager.execute_snmp_get()` 在 SNMP v3 下改为透传用户名
  - `snmp_get_oid()` 的 v3 OID 查询改为使用 `UsmUserData`

  - 本机直连结果处理改为写入 `plan_*` 集合和本地结果表
  - 本地执行成功后同步回写设备事实

- 南向驱动执行链路测试
  - 覆盖 Netmiko payload 组装与 `textfsm_template`
  - 覆盖 NETCONF `filter` 包裹、`get/get_config` URL 分支
  - `NETCONF` 无 XML 模板时统一返回 `{"success": false, "error": "未配置XML模板"}`
- 序列化器与执行入口边界补齐
  - `_build_device_info_for_local()` 增加 SNMP v3 `username/auth_key/priv_key` 透传
  - 增加子方案创建/更新序列化器的必填校验测试
  - 增加 `validate_execution_params` 与 `execute_sub_plan` 本地入口测试
- MongoDB 复合索引落地
  - 新增 `indexes.py` 统一维护 `plan_*` / `TestDeviceCollection` / Celery 结果集合索引
  - 新增 `ensure_device_api_indexes` 管理命令
  - `DeviceApiConfig.ready()` 在安全场景下 best-effort 确保索引

## 3. 本轮已落地能力

### 3.1 父方案主导配置

已落地：

- `DeviceCollectionPlans` 新增方案级采集类型和采集方式字段
- 父方案 `create/update/sync_collect_plans` 会自动：
  - 创建缺失子方案
  - 关闭未选中的采集类型
  - 同步 `netmiko_enabled/netconf_enabled`

相关文件：

- `backend/apps/device_api/models.py`
- `backend/apps/device_api/services_new.py`
- `backend/apps/device_api/serializers.py`
- `backend/apps/device_api/views.py`
- `backend/apps/device_api/migrations/0009_summary_plan_sync_config.py`

### 3.2 方案级字段映射聚合

已落地接口：

- `GET /base_platform/device_api/collection-plans/{id}/field-mappings/`
- `PATCH /base_platform/device_api/collection-plans/{id}/field-mappings/`

用途：

- 以 `collection_type` 聚合展示各子方案的 `*_path` 和 `*_field_mappings`
- 支持按父方案维度批量回写

### 3.3 方案级一键验证

已落地接口：

- `POST /base_platform/device_api/collection-plans/{id}/validate/`

用途：

- 对父方案下所有已启用子方案做一次聚合验证
- 支持：
  - `use_local=true` 本机直连
  - 传 `south_driver` 走南向驱动
- 返回结果按 `collection_type` 分组

### 3.4 NETCONF 处理器补齐

已补齐 H3C：

- `arp/netconf`
- `mac/netconf`
- `ip_interface/netconf`
- `lldp/netconf`
- `aggre_port/netconf`
- `mac_evpn/netconf`

已补齐 Huawei：

- `arp/netconf`
- `mac/netconf`
- `ip_interface/netconf`
- `lldp/netconf`
- `aggre_port/netconf`

说明：

- 解析逻辑优先复用了 `automation/tools/h3c.py` 和 `automation/tools/huawei.py` 的旧语义，降低行为漂移风险
- 当前 H3C/Huawei 的常见 NETCONF 结构已由 `apps.device_api.tests` 覆盖

### 3.5 预处理与字段映射回归测试

已补齐：

- `resolve_raw_data`
  - 处理器命中时优先返回，不再进入 `tools/`
  - 处理器抛 `NotImplementedError` 时回退到 `tools/`
  - NETCONF 无处理器时明确返回 `netconf_no_processor`
- `apply_field_mappings`
  - 支持 `top.xxx[*].field` 形式的嵌套数组路径
  - 支持 `path_config="payload.items"` + 相对字段路径
  - 缺失或非数组路径时返回空列表，避免静默错取值

### 3.6 连接管理与 SNMP v3 修复

已补齐：

- `DeviceConnectionManager`
  - 覆盖 SSH 缺账号异常
  - 覆盖 RESTCONF token 会话配置
  - 覆盖 Telemetry 缺少 `grpcio` 依赖时的报错
  - 修复 SNMP v3 执行时误传 community、未传 username 的问题
- `utils.connect_layer.snmp.snmp_test.snmp_get_oid`
  - v3 OID 查询改为使用 `UsmUserData`
  - 保持 v2c 仍走 `CommunityData`

### 3.7 本地执行链路补齐

已补齐：

- `services_new._process_collection_result`
  - 成功时补齐 metadata/context 后写入 `plan_<collection_type>` 集合
  - 成功时写入 `COLLECTION_RESULTS_DB` 本地结果记录
  - 成功时触发设备事实回写
  - 失败时也写入本地错误结果，便于排查
- `services_new.collect_with_connection_manager`
  - 已通过测试覆盖“单协议失败但其他协议成功”时的聚合返回
  - `success_methods` 只包含真实成功的协议

### 3.8 南向驱动执行链路测试

已补齐：

- `_execute_netmiko_south`
  - 覆盖 `device_type` 映射、`textfsm_template` 透传、webhook 参数
- `_execute_netconf_south`
  - 覆盖裸 XML 自动包裹 `<filter type="subtree">`
  - 覆盖 `collect_method=get` 与 `get_config` 的 URL/args 分支
  - 无 XML 模板时统一返回明确失败信息

### 3.9 序列化器与执行入口边界补齐

已补齐：

- `services_new._build_device_info_for_local`
  - 增加 SNMP v3 所需的 `snmp_username` / `snmp_auth_key` / `snmp_priv_key` 透传
- `DeviceSubCollectionPlanCreateSerializer` / `DeviceSubCollectionPlanUpdateSerializer`
  - 覆盖 `summary_plan_id`、`xml_templates`、`snmp_oids`、`telemetry_subscription_path` 等必填校验
- `DeviceSubCollectionPlanViewSet`
  - 覆盖 `validate_execution_params` 在本地/南向模式下对 SNMP 的分流逻辑
  - 覆盖 `execute_sub_plan` 的 `use_local=true` 入口

### 3.10 MongoDB 复合索引落地

已补齐：

- `apps.device_api.indexes`
  - 统一声明 `plan_*`、`TestDeviceCollection`、`PlanCollectionCelery`、`SubPlanCollectionCelery` 的复合索引
  - 提供 `ensure_device_api_mongo_indexes()` 和 `bootstrap_device_api_mongo_indexes()`
- `apps.device_api.apps.DeviceApiConfig.ready()`
  - 在非 `test` / `migrate` / `makemigrations` 等命令下 best-effort 自动确保索引
  - 支持通过 `DEVICE_API_SKIP_AUTO_INDEXES=1` 跳过自动建索引
- `management/commands/ensure_device_api_indexes.py`
  - 提供显式索引确保入口，便于在目标环境手工执行
