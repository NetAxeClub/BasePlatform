# 开发环境配置

## 1. 环境要求

### 1.1 系统要求
- **操作系统**: Linux / macOS / Windows (推荐Linux或macOS)
- **Python版本**: Python 3.8+
- **数据库**: 
  - MySQL 5.7+ 或 MySQL 8.0+
  - MongoDB 4.0+
  - Redis 5.0+

### 1.2 开发工具
- **IDE**: PyCharm / VSCode
- **版本控制**: Git
- **容器**: Docker & Docker Compose (可选，用于本地开发)

## 2. 环境安装

### 2.1 Python环境

#### 使用pyenv管理Python版本（推荐）
```bash
# 安装pyenv
curl https://pyenv.run | bash

# 安装Python 3.8+
pyenv install 3.8.16
pyenv local 3.8.16
```

#### 使用conda
```bash
conda create -n netaxe python=3.8
conda activate netaxe
```

### 2.2 数据库安装

#### MySQL
```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install mysql-server

# macOS
brew install mysql
brew services start mysql

# 创建数据库
mysql -u root -p
CREATE DATABASE netaxe CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

#### MongoDB
```bash
# Ubuntu/Debian
sudo apt-get install mongodb

# macOS
brew install mongodb-community
brew services start mongodb-community

# 启动MongoDB
mongod --dbpath /data/db
```

#### Redis
```bash
# Ubuntu/Debian
sudo apt-get install redis-server

# macOS
brew install redis
brew services start redis
```

### 2.3 项目依赖安装

```bash
# 进入项目目录
cd /path/to/BasePlatform/backend

# 创建虚拟环境（如果使用venv）
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# 或
venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

## 3. 配置文件

### 3.1 数据库配置

编辑 `config/config.json`:

```json
{
  "mysql_host": "localhost",
  "mysql_port": 3306,
  "mysql_user": "root",
  "mysql_password": "your_password",
  "mysql_db": "netaxe",
  "mongodb_host": "localhost",
  "mongodb_port": 27017,
  "mongodb_user": "",
  "mongodb_password": "",
  "mongodb_db": "Automation",
  "redis_host": "localhost",
  "redis_port": 6379,
  "redis_pwd": "",
  "local_dev": true
}
```

### 3.2 Django设置

主要配置在 `backend/netaxe/settings.py`，通常不需要修改，配置从 `config/config.json` 读取。

## 4. 数据库初始化

### 4.1 创建数据库表

```bash
cd backend
python manage.py makemigrations
python manage.py migrate
```

### 4.2 初始化数据

```bash
# 初始化资产数据
python manage.py init_asset

# 初始化系统菜单（如果有）
python manage.py init_system_menu
```

### 4.3 创建超级用户

```bash
python manage.py createsuperuser
```

## 5. 启动服务

### 5.1 开发模式启动

#### 启动Django开发服务器
```bash
cd backend
python manage.py runserver 0.0.0.0:8000
```

#### 启动Celery Worker
```bash
# 启动默认队列Worker
celery -A netaxe worker -l info -Q default

# 启动配置备份队列Worker
celery -A netaxe worker -l info -Q config_backup

# 启动配置队列Worker
celery -A netaxe worker -l info -Q config
```

#### 启动Celery Beat（定时任务）
```bash
celery -A netaxe beat -l info
```

#### 启动Daphne（WebSocket支持）
```bash
daphne -b 0.0.0.0 -p 8001 netaxe.asgi:application
```

### 5.2 使用Docker Compose启动（推荐）

```bash
# 构建镜像
docker-compose build

# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

## 6. 开发工具配置

### 6.1 PyCharm配置

1. **打开项目**: File -> Open -> 选择项目目录
2. **配置Python解释器**: File -> Settings -> Project -> Python Interpreter
   - 选择虚拟环境中的Python解释器
3. **配置Django**: File -> Settings -> Languages & Frameworks -> Django
   - Enable Django Support
   - Django project root: `backend`
   - Settings: `netaxe.settings`
4. **配置运行配置**:
   - Run -> Edit Configurations
   - 添加Django Server配置
   - 添加Celery Worker配置

### 6.2 VSCode配置

创建 `.vscode/settings.json`:

```json
{
  "python.defaultInterpreterPath": "${workspaceFolder}/backend/venv/bin/python",
  "python.linting.enabled": true,
  "python.linting.pylintEnabled": true,
  "files.exclude": {
    "**/__pycache__": true,
    "**/*.pyc": true
  }
}
```

## 7. 代码规范

### 7.1 Python代码规范
- 遵循PEP 8规范
- 使用4个空格缩进
- 行长度不超过120字符
- 使用类型提示（Type Hints）

### 7.2 Django代码规范
- 使用Django REST Framework的ViewSet
- 模型字段使用verbose_name
- 使用Django的ORM而不是原生SQL
- 使用Django的中间件处理通用逻辑

### 7.3 Git提交规范
- 提交信息使用中文
- 格式: `<类型>: <描述>`
- 类型: feat(新功能)、fix(修复)、docs(文档)、style(格式)、refactor(重构)、test(测试)、chore(构建)

## 8. 调试技巧

### 8.1 Django调试
- 使用Django Debug Toolbar（开发环境）
- 查看Django日志: `backend/logs/server.log`
- 使用Django Shell: `python manage.py shell`

### 8.2 Celery调试
- 查看Celery日志: `backend/logs/celery.log`
- 使用Flower监控: `celery -A netaxe flower`
- 访问 http://localhost:5555 查看任务状态

### 8.3 数据库调试
- 查看数据库日志: `backend/logs/db.log`
- 使用Django Admin查看数据: http://localhost:8000/admin/

### 8.4 WebSocket调试
- 查看WebSocket日志: `backend/logs/websocket.log`
- 使用浏览器开发者工具查看WebSocket连接

## 9. 常见问题

### 9.1 数据库连接失败
- 检查数据库服务是否启动
- 检查配置文件中的连接信息
- 检查数据库用户权限

### 9.2 Celery任务不执行
- 检查Redis连接
- 检查Worker是否启动
- 检查队列名称是否匹配

### 9.3 WebSocket连接失败
- 检查Daphne是否启动
- 检查Redis Channel Layer配置
- 检查路由配置

### 9.4 导入错误
- 检查Python路径
- 检查虚拟环境是否激活
- 检查依赖是否安装完整

## 11. 性能优化

### 11.1 数据库优化
- 使用数据库索引
- 使用select_related和prefetch_related减少查询
- 使用数据库连接池

### 11.2 缓存优化
- 使用Redis缓存热点数据
- 使用Django缓存框架
- 合理设置缓存过期时间

### 11.3 Celery优化
- 合理设置Worker并发数
- 使用任务优先级
- 避免长时间运行的任务
