# 网络设备数据采集方案 - 前端交互设计稿

## 1. 设计概述

### 1.1 设计目标
- **简单易用**：提供直观的操作界面，降低用户学习成本
- **流程清晰**：按照"配置方案 → 关联设备 → 执行采集 → 查看结果"的流程组织功能
- **高效便捷**：支持批量操作、快速配置、一键执行
- **信息透明**：实时展示采集状态、执行进度、错误信息

### 1.2 设计原则
- **渐进式配置**：分步骤引导用户完成复杂配置
- **所见即所得**：配置过程中实时预览效果
- **智能提示**：提供字段说明、格式验证、错误提示
- **快速反馈**：操作后立即显示结果，异步任务提供状态更新

### 1.3 页面结构
```
主菜单导航
├── 采集方案管理
│   ├── 父采集方案列表
│   ├── 子采集方案列表
│   └── 采集模板管理
│       ├── NETCONF XML模板
│       ├── SNMP OID配置
│       ├── RESTCONF端点配置
│       └── Telemetry订阅配置
├── 设备关联管理
│   ├── 设备方案关联列表
│   └── 批量关联操作
├── 采集任务执行
│   ├── 单设备采集
│   ├── 批量采集
│   └── 定时任务配置
├── 采集结果查询
│   ├── 数据查询
│   ├── 结果详情
│   └── 数据导出
└── 任务监控统计
    ├── 任务状态监控
    ├── 采集统计概览
    └── 执行日志查看
```

## 2. 核心页面设计

### 2.1 采集方案管理

#### 2.1.1 父采集方案列表页

**页面布局**：
```
┌─────────────────────────────────────────────────────────────┐
│  采集方案管理 > 父采集方案                                    │
├─────────────────────────────────────────────────────────────┤
│  [搜索框: 方案名称/厂商/设备类型]  [筛选: 厂商▼] [筛选: 状态▼] │
│  [+ 新建父采集方案]                                          │
├─────────────────────────────────────────────────────────────┤
│  方案名称        │ 厂商    │ 设备类型 │ 状态 │ 子方案数 │ 操作 │
├─────────────────────────────────────────────────────────────┤
│  华为交换机采集  │ 华为    │ 交换机   │ 启用 │   6     │ 编辑 │
│  方案            │         │          │      │         │ 删除 │
│                  │         │          │      │         │ 查看子方案│
├─────────────────────────────────────────────────────────────┤
│  华三路由器采集  │ 华三    │ 路由器   │ 启用 │   5     │ ... │
│  方案            │         │          │      │         │     │
├─────────────────────────────────────────────────────────────┤
│  [分页: 共20条, 每页10条]                                    │
└─────────────────────────────────────────────────────────────┘
```

**功能说明**：
- **搜索功能**：支持按方案名称、厂商、设备类型模糊搜索
- **筛选功能**：支持按厂商、启用状态筛选
- **新建按钮**：点击后打开父采集方案创建表单
- **操作列**：
  - **编辑**：修改方案基本信息
  - **删除**：删除方案（需确认，同时删除关联的子方案）
  - **查看子方案**：跳转到该父方案下的子方案列表
  - **启用/禁用**：快速切换方案状态

**交互流程**：
1. 用户进入页面，自动加载方案列表
2. 可通过搜索框或筛选器快速定位方案
3. 点击"新建"按钮，弹出创建表单
4. 点击"查看子方案"，跳转到子方案列表页（自动过滤）

**页面布局**：
```

│                                                              │
│  设备类型 *                                                  │
│  [下拉选择: 交换机 ▼]                                        │
│  选项: 交换机、路由器、防火墙                                 │
│                                                              │
│  描述                                                        │
│  [多行文本: 用于采集华为交换机的网络数据...]                  │
│                                                              │
│  启用状态                                                    │
│  [开关: ● 启用]                                              │
│                                                              │
│  [取消]  [保存]                                              │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

**功能说明**：
- **表单验证**：
  - 方案名称：必填，长度1-100字符，唯一性校验
  - 厂商：必填，从预定义列表选择
  - 设备类型：必填，从预定义列表选择
  - 描述：可选，最多500字符
- **实时校验**：输入时实时检查格式，失焦时检查唯一性
- **保存操作**：点击保存后显示加载状态，成功后关闭表单并刷新列表

**交互流程**：
1. 用户填写表单信息
2. 实时显示验证结果（成功✓/失败✗）
3. 点击保存，显示"保存中..."
4. 保存成功：提示"创建成功"，关闭表单，刷新列表
5. 保存失败：显示错误信息，表单保持打开状态

**字段映射配置交互**：
- **从模板加载**：点击后弹出模板选择框，选择采集类型后自动加载标准字段映射
- **添加字段映射**：点击后弹出字段选择器，选择标准字段，然后输入字段路径
- **字段路径提示**：
  - Netmiko/NETCONF：支持 `data[*].field_name` 格式（从数组元素提取）
  - SNMP：支持OID选择或直接输入OID值
  - RESTCONF：支持JSON路径，如 `ietf-interfaces:interfaces[*].name`
  - Telemetry：支持GPB路径或JSON路径
  - 所有方式：支持 `top_level_key` 格式（从顶层提取）、常量值（直接输入值）

- **实时预览**：配置过程中可点击"预览"查看映射效果
- **标签页切换**：不同采集方式的字段映射配置在独立标签页中，避免混淆

## 3. 交互细节设计

### 3.1 表单验证与提示

**实时验证**：
- 输入框失焦时立即验证
- 验证通过显示绿色✓，失败显示红色✗和错误信息
- 保存按钮在表单无效时禁用

**采集方式特定验证**：
- **Netmiko**：验证命令格式，检查TextFSM模板路径是否存在
- **NETCONF**：验证XML模板格式，检查XML语法
- **SNMP**：验证OID格式（如 1.3.6.1.2.1.4.22.1.2），检查SNMP版本和社区字符串
- **RESTCONF**：验证URL格式，检查HTTP方法选择
- **Telemetry**：验证订阅路径格式，检查采样间隔范围（1-3600秒）

**错误提示**：
- 字段级错误：在输入框下方显示红色错误信息
- 表单级错误：在表单顶部显示错误摘要
- 网络错误：使用Toast提示，显示具体错误信息
- 采集方式错误：显示具体采集方式的错误原因和解决建议

**成功提示**：
- 操作成功使用Toast提示（如"创建成功"）
- 重要操作（如删除）使用确认对话框
- 采集任务提交成功：显示任务ID和预计完成时间

### 3.2 加载状态反馈

**按钮加载状态**：
- 点击按钮后，按钮文字变为"处理中..."，禁用按钮
- 显示加载图标（旋转动画）

**页面加载状态**：
- 列表页：显示骨架屏或加载动画
- 表单页：禁用所有输入，显示加载遮罩

**数据刷新**：
- 自动刷新：定时任务列表每5秒自动刷新
- 手动刷新：点击刷新按钮，显示刷新动画

### 3.3 状态标识

**任务状态**：
- ✓ 成功：绿色对勾
- ⏳ 执行中：蓝色旋转图标
- ✗ 失败：红色叉号
- ⚠ 警告：黄色感叹号

**启用状态**：
- ● 启用：绿色开关
- ○ 禁用：灰色开关

**采集方式状态**：
- ✓ 已启用：绿色对勾（Netmiko、NETCONF、SNMP、RESTCONF、Telemetry）
- ✗ 未启用：灰色叉号
- ⚠ 配置不完整：黄色警告（如启用了NETCONF但未配置XML模板）

**采集方式图标**：
- Netmiko：终端图标
- NETCONF：XML图标
- SNMP：网络图标
- RESTCONF：API图标
- Telemetry：流式数据图标

### 3.4 快捷操作

**批量操作**：
- 列表页支持全选/反选
- 选中后显示批量操作工具栏（删除、批量关联等）
- 批量操作前显示确认对话框

**快速筛选**：
- 常用筛选条件保存为快捷标签
- 支持多条件组合筛选
- 筛选条件可保存为视图

**快速搜索**：
- 搜索框支持自动补全
- 支持搜索历史记录
- 支持高级搜索（多字段组合）

### 3.5 数据展示优化

**表格优化**：
- 支持列排序（点击表头）
- 支持列显示/隐藏配置
- 支持列宽调整
- 长文本自动截断，鼠标悬停显示完整内容

**分页优化**：
- 显示总记录数和当前页范围
- 支持跳转到指定页
- 支持调整每页显示数量

**数据导出**：
- 支持导出当前页或全部数据
- 支持选择导出字段
- 导出时显示进度条

## 6. 技术实现建议

### 6.1 前端框架
- 推荐使用 Vue 3 + Element Plus 或 React + Ant Design
- 使用 TypeScript 提升代码质量
- 使用状态管理库（Vuex/Pinia 或 Redux）管理全局状态

### 6.2 组件库
- 使用成熟的UI组件库，减少开发工作量
- 自定义业务组件，封装常用功能
- 建立组件文档，方便团队协作

### 6.3 数据交互
- 使用 Axios 或 Fetch 进行HTTP请求
- 统一封装API请求，处理错误和加载状态
- 使用WebSocket实现实时状态更新
- 采集任务状态轮询（每3-5秒）或WebSocket推送

### 6.4 状态管理
- 采集任务状态使用WebSocket实时推送或轮询
- 列表数据使用分页加载，避免一次性加载大量数据
- 表单数据使用本地状态管理，提交时验证
- 采集方式配置状态管理（5种采集方式的启用/禁用状态）

### 6.5 采集方式配置组件
- **Netmiko配置组件**：命令输入、TextFSM模板选择、路径配置
- **NETCONF配置组件**：XML模板编辑器、采集方法选择
- **SNMP配置组件**：OID输入/选择器、版本选择、MIB导入
- **RESTCONF配置组件**：端点URL输入、HTTP方法选择、请求头配置
- **Telemetry配置组件**：订阅路径输入、采样间隔配置、数据格式选择

### 6.6 字段映射组件
- 支持5种采集方式的字段映射配置
- 提供字段路径自动补全（根据原始数据结构）
- 支持从模板快速加载标准字段映射
- 实时预览字段映射效果

## 8. 总结

本设计稿提供了完整的网络设备数据采集系统的前端交互设计方案，支持5种采集方式（Netmiko、NETCONF、SNMP、RESTCONF、Telemetry），通过分步骤向导、实时反馈、智能提示等方式，确保用户能够简单、方便、快捷地完成设备数据采集方案的配置和执行。

### 8.1 核心设计亮点
- **多采集方式支持**：统一界面支持5种采集方式配置，降低学习成本
- **连接复用可视化**：清晰展示单设备采集时的连接复用状态，提升用户对系统效率的认知
- **渐进式配置**：4步向导引导用户完成复杂配置，降低配置错误率
- **智能验证**：针对不同采集方式提供特定的验证规则和错误提示
- **实时状态反馈**：采集任务状态实时更新，支持多种采集方式的状态展示

### 8.2 用户体验优化
- **所见即所得**：配置过程中实时预览效果
- **智能提示**：根据采集类型自动推荐合适的采集方式和字段映射模板
- **错误友好**：提供详细的错误信息和解决建议
- **操作便捷**：支持批量操作、快速筛选、一键执行

设计遵循了用户体验最佳实践，注重操作的直观性和反馈的及时性，能够有效提升用户的工作效率，确保系统支持多种采集方式的同时保持简单易用的特性。
