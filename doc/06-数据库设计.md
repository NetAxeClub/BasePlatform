# 数据库设计

## 1. 数据库概述

NetAxe平台使用多种数据库存储不同类型的数据：
- **MySQL**: 存储结构化业务数据
- **MongoDB**: 存储采集的原始数据和解析结果
- **Redis**: 缓存和消息队列

## 3. MongoDB数据库设计

MongoDB主要用于存储设备采集的原始数据和解析结果，数据库名为 `Automation`。

### 3.1 主要集合

#### layer3interface - 三层接口信息
```json
{
  "_id": ObjectId("..."),
  "hostip": "192.168.1.1",
  "interface": "GigabitEthernet1/0/1",
  "ip": "10.1.1.1",
  "mask": "255.255.255.0",
  "status": "up",
  "collect_time": ISODate("2024-01-01T00:00:00Z")
}
```

#### arp - ARP表
```json
{
  "_id": ObjectId("..."),
  "hostip": "192.168.1.1",
  "ip": "10.1.1.2",
  "mac": "00:11:22:33:44:55",
  "interface": "GigabitEthernet1/0/1",
  "age": 100,
  "collect_time": ISODate("2024-01-01T00:00:00Z")

```

```json

  "_id": ObjectId("..."),

```

## 4. Redis数据结构

### 4.1 缓存数据
- **键格式**: `cache:{key}`
- **用途**: 缓存热点数据，如设备信息、采集结果等
- **过期时间**: 根据业务需求设置（默认2小时）

### 4.2 Celery消息队列
- **队列**: 
  - `celery`: 默认队列
  - `config_backup`: 配置备份队列
  - `config`: 配置相关队列
- **结果存储**: 使用Django数据库存储任务结果

### 4.3 WebSocket Channel Layer
- **键格式**: `asgi:group:{group_name}`
- **用途**: WebSocket消息通道

### 4.4 会话存储
- **键格式**: `session:{session_key}`
- **用途**: Django会话存储

## 5. 数据库索引

### 5.1 MySQL索引

#### asset_networkdevice表
- `serial_num`: 唯一索引
- `manage_ip`: 普通索引
- `vendor_id`: 外键索引
- `status`: 普通索引（用于筛选）

#### config_backup表
- `host`: 普通索引
- `backup_time`: 普通索引
- `(host, config_type, backup_time)`: 复合索引

#### auto_flow表
- `task_id`: 唯一索引
- `device`: 普通索引
- `state`: 普通索引
- `commit_time`: 普通索引

### 5.2 MongoDB索引

#### layer3interface集合
```javascript
db.layer3interface.createIndex({ "hostip": 1, "collect_time": -1 })
db.layer3interface.createIndex({ "hostip": 1, "interface": 1 })
```

#### arp集合
```javascript
db.arp.createIndex({ "hostip": 1, "collect_time": -1 })
db.arp.createIndex({ "hostip": 1, "ip": 1 })
```

#### mac集合
```javascript
db.mac.createIndex({ "hostip": 1, "collect_time": -1 })
db.mac.createIndex({ "mac": 1 })
```

## 6. 数据关系

### 6.1 外键关系
- `asset_networkdevice.vendor_id` → `asset_vendor.id`
- `asset_networkdevice.idc_id` → `asset_idc.id`
- `asset_networkdevice.category_id` → `asset_category.id`
- `asset_networkdevice.model_id` → `asset_model.id`
- `asset_networkdevice.role_id` → `asset_role.id`
- `device_api_sub_collection_plan.parent_plan_id` → `device_api_collection_plans.id`

### 6.2 数据同步
- CMDB设备信息定期同步到MongoDB的`networkdevice`集合
- 采集数据从MongoDB读取，处理后更新MySQL相关表

## 7. 数据备份

### 7.1 MySQL备份
```bash
# 备份数据库
mysqldump -u root -p netaxe > netaxe_backup.sql

# 恢复数据库
mysql -u root -p netaxe < netaxe_backup.sql
```

### 7.2 MongoDB备份
```bash
# 备份数据库
mongodump --db Automation --out /backup/mongodb

# 恢复数据库
mongorestore --db Automation /backup/mongodb/Automation
```

### 7.3 Redis备份
```bash
# 备份RDB文件
cp /var/lib/redis/dump.rdb /backup/redis/

# 或使用AOF
redis-cli BGREWRITEAOF
```
