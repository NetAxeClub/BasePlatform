# 风险台账与豁免记录

## 1. 使用说明

本文件是 NetClaw-CN 改造在 NetAxe backend 侧的全局风险账本。

所有阶段风险、残余问题、豁免和复核结果均必须登记在本文件中。未登记风险不视为正式存在，未登记豁免不允许口头放行。

## 2. 风险字段规范

每条风险必须至少包含：

- 风险 ID
- 所属阶段
- 风险标题
- 影响范围
- 当前状态
- 缓解措施
- 关闭条件
- 负责人
- 最近更新时间

建议状态值：

- `OPEN`
- `MITIGATING`
- `WAIVED`
- `CLOSED`

## 3. 豁免字段规范

每条豁免必须至少包含：

- 豁免 ID
- 绑定阶段
- 绑定风险 ID
- 豁免原因
- 影响范围
- 截止时间
- 复核条件
- 当前状态

建议状态值：

- `ACTIVE`
- `EXPIRED`
- `CLOSED`

## 7. 维护规则

- 风险项由研发负责人或验收负责人提出
- 豁免项只能由验收负责人在正式结论中批准
- 风险关闭必须写明关闭依据
- 过期豁免必须重新复核，不能自动延续
