# 安全策略统一审计接口

## 目标

为 H3C / Huawei / Hillstone 防火墙提供统一的安全策略查询输出，便于 NetClaw-CN 直接复用，不再依赖厂商私有字段做二次猜测。

## 接口

- 路径：`GET /base_platform/dcs_control/sec_policy_audit/`
- 必填参数：
  - `hostip`：设备管理 IP
- 可选参数：
  - `vendor`：`H3C` / `Huawei` / `Hillstone`

说明：

- 当前接口基于 `Automation.sec_policy` 中已标准化落库的策略数据进行聚合。
- `vendor` 仅作为过滤条件与展示值，不传时默认返回该设备在标准化库中的全部策略。

留痕接口：

- 路径：`GET /base_platform/dcs_control/sec_policy_audit_records/`
- 路径：`POST /base_platform/dcs_control/sec_policy_audit_records/`

说明：

- `POST` 支持两种模式：
  - 直接写入外部系统已经生成好的 `audit_payload / summary / findings`
  - 仅传 `device_ip` 与可选 `vendor`，由平台基于当前 `sec_policy` 数据自动生成审计快照并落库
- 记录模型支持关联 `auto_flow_id`、`task_id`，便于后续和 `AutoFlow` 或 inspection domain 对接

## 统一输出字段

单条策略字段：

- `vendor`：规范化厂商名
- `hostip`：设备管理 IP
- `rule_id`：策略 ID
- `rule_name`：策略名称
- `description`：策略描述
- `action`：`permit` / `deny`
- `enabled`：策略是否启用
- `logging_state`：`enabled` / `disabled` / `unknown`
- `source_zones`：源安全域列表
- `destination_zones`：目的安全域列表
- `source_addresses`：源地址列表，统一为 `{type, value}`
- `destination_addresses`：目的地址列表，统一为 `{type, value}`
- `services`：服务列表，统一为 `{kind, name, protocol, start_port, end_port, display, is_any, is_high_risk}`
- `has_any_source`：是否放通任意源
- `has_any_destination`：是否放通任意目的
- `has_any_service`：是否放通任意服务
- `is_permit_any_any`：是否命中 `permit-any-any` 风险
- `has_high_risk_service`：是否放通高危端口服务
- `high_risk_services`：命中的高危服务条目
- `needs_logging_review`：是否需要补充策略日志
- `findings`：风险标签列表

聚合摘要字段：

- `hostip`
- `vendor`
- `total_rules`
- `enabled_rules`
- `permit_any_any_count`
- `high_risk_service_rule_count`
- `logging_review_count`

## 当前限制

- 高危服务识别当前优先基于标准化后的显式端口条目；仅引用服务对象名而未展开端口时，不强行推断高危端口。
- `logging_state=unknown` 表示底层标准化数据未稳定提供日志字段，建议上层将其视为待人工确认。
